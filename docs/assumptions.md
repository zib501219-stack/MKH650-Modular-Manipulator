# Assumptions

- Rated payload and 1180 mm radius follow the confirmed project report/resume baseline.
- Link split 520 + 480 + 180 mm is selected to reproduce the total radius while leaving realistic joint space.
- Link and tool masses used for preliminary sizing are estimates pending native CAD material mass properties.
- Motors, reducers, bearings, lubrication blocks and pneumatic components are envelope models.
- Source model is a reconstruction because the historical native assembly was unavailable.
