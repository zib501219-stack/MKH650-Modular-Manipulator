# 轴系、轴承支撑与关键连接件初步校核

本文件补充简历中“检查传动轴、轴承支撑和连接件”的设计证据。所有结果用于方案阶段尺寸确定，不代替供应商寿命计算、焊缝评定或实体样机测试。

## 1. 输入条件

- 额定负载：20 kg
- 最大工作半径：1180 mm
- J2初步设计输出扭矩：1552 N·m
- 夹持机构目标总夹紧力：约1.8 kN
- 输出轴材料假定：40Cr调质
- 关节支撑形式：减速器、交叉滚子轴承和中空输出轴同轴布置

## 2. J2输出轴扭转检查

J2输出轴方案直径取90 mm。按实心圆轴纯扭转公式：

`τ = 16T / (πd³)`

代入 `T = 1552 N·m`、`d = 90 mm`，名义扭转剪应力约10.8 MPa。实际中空轴、台阶、键槽和法兰过渡会提高局部应力，详细设计时需要按真实截面复核。

## 3. 轴承与支撑

- J1采用回转支承包络，承担整机轴向载荷、径向载荷和倾覆力矩
- J2/J3采用交叉滚子轴承包络，减速器输出与轴承中心尽量靠近，减少悬臂距离
- 轴承座设置止口和轴肩，螺栓主要提供夹紧力
- 轴承安装面、法兰端面和输出轴同轴面需要规定统一加工与检测基准
- 定型时需按供应商样本复核静载、动载、倾覆力矩、寿命和润滑条件

## 4. 法兰和连接件

- J1基础法兰采用16点锚固，J2/J3关节采用12点法兰连接
- 定位止口承担径向定位，均布高强螺栓提供预紧与摩擦传力
- 关键法兰预留圆柱销或复检孔，避免拆装后位置漂移
- 大臂、小臂双侧板之间使用横向筋板和定位结构，限制侧板相对扭转
- 服务盖板、拖链和润滑接口预留拆装空间，避免维护时拆卸主承载结构

## 5. 夹持机构

按20 kg工件、摩擦系数0.25和安全系数2.25估算，总夹紧力约1.77 kN，方案按1.8 kN设计。夹指采用可更换防滑垫，并预留压力监测和失压保护方案。

## 6. 验证边界

当前校核能够支持轴径、轴承包络、法兰尺寸和夹持力的方案选择。焊缝疲劳、轴肩疲劳、轴承寿命、螺栓预紧力和动态冲击仍需详细计算、求解器分析或实机验证。
