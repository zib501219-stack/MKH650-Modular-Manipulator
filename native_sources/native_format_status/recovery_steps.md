# 原生格式补齐路径

## NX 12

1. 在具有 `SOLIDS MODELING`/建模模块许可的 NX 12 环境启动。
2. 运行 `generate_portfolio_nx.py`，或逐个导入 `enhanced_key_parts/*.step`。
3. 对导入体执行几何检查，按零件号保存为 `.prt`。
4. 建立原生装配并给零件命名，添加同心、贴合、距离和角度约束。
5. 按 `collision_validation/overlap_pairs.csv` 逐项分类：预期配合、紧固件穿入、建模重叠、真实干涉。
6. 修正真实干涉后重新导出 STEP，并再次运行碰撞筛查。

## SolidWorks

1. 已完成的基础 `.SLDPRT` 可直接编辑。
2. 增强件可打开相应 STEP，启用 3D Interconnect 或用“导入诊断”修复后另存 `.SLDPRT`。
3. 若要完整特征树，以同目录参数化脚本和 PDF/DXF 尺寸为依据重建草图、孔向导、圆角和阵列。
4. 原生装配完成后运行干涉检查，并保存带零件名的报告。

## AutoCAD

1. 直接打开 `engineering_package/drawings_dxf/` 中的 DXF。
2. 检查单位为毫米、字体替代和线型映射。
3. 需要 DWG 时在 AutoCAD 中“另存为”当前版本 DWG；PDF 是版面预览，不是可编辑源文件。

## 三维结构分析

1. 先完成无干涉、带材料的原生装配。
2. 对机器人侧板/关节座和检测线底板分别建立实体或壳单元模型。
3. 把轴承、螺栓和导轨连接按实际刚度建模，载荷沿真实传力路径施加。
4. 至少进行两级网格细化，并记录最大应力位置、位移和收敛变化。
5. 将结果与 `structural_analysis/` 的整体梁结果对照；若差异大，优先排查局部连接、边界刚化和截面等效假设。
