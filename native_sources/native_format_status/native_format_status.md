# 原生 CAD 格式交付状态

## 已完成并验证

- SolidWorks 2023：每个项目 4 个真实 `.SLDPRT` 零件，包含可编辑草图和拉伸特征；生成记录中的错误数为 0。
- STEP：基础零件、增强关键零件、爆炸参考装配和系统详细模型均保留为中性实体格式；增强关键零件已回读为单实体。
- AutoCAD 通用源文件：工程图以可编辑 ASCII DXF 交付，并同时提供 A3 PDF 预览。
- 参数化重建源：增强零件保留 CadQuery Python 源码，结构分析和运动/节拍验证保留可重复执行的源码与输入输出。

## 尚未伪造为“已完成”的内容

- NX 12 原生特征 `.prt`：NX 能启动，但本机执行特征建模时返回许可证模块错误 `-10005`，因此没有把空文件或改后缀文件冒充 NX 源文件。
- 原生受约束装配：当前系统级 STEP 是多实体布置模型；碰撞筛查发现大量实体交叠，尚不能声明为可制造、无干涉的原生装配。
- 原生三维实体 FEA：本机没有可用的 NX/ANSYS/CalculiX 求解环境。本仓库交付的是有明确截面、材料、载荷和边界条件的一维梁有限元初筛，并明确列出不适用范围。
- 增强 STEP 批量转 SolidWorks：自动导入接口未能打开这些 STEP，因此增强版继续以 STEP + 参数化生成脚本交付；基础版 `.SLDPRT` 不受影响。

## 证据文件

- `nx_generation_report.json`：NX 特征建模失败栈及 `-10005` 许可证错误。
- `solidworks_generation_report.json`：基础原生零件生成成功记录。
- `solidworks_conversion_report.json`：增强 STEP 自动导入失败记录。

这些记录用于区分“文件已验证”“可继续重建”和“受本机许可证限制”，避免作品集出现无法解释的假原生文件。
